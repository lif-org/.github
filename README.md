# Welcome to lif-org 👋

**lif** is the next-generation package management ecosystem for Luau and Roblox developers. We focus on speed, security, and seamless integration with existing workflows.

### 🛠 Our Core Projects
* **[lif-cli](https://github.com/lif-org/lif-cli):** The primary command-line interface for installing, publishing, and managing Luau packages.
* **[lif-registry](https://github.com/lif-org/lif-registry):** The backend infrastructure and web interface hosting our official package database.

---

### 🚀 Getting Started
Ready to manage your dependencies with `lif`? 

```bash
# Install the CLI
npm install -g @lif/cli

# Initialize a new project
lif init
```
